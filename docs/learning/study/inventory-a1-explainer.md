## Confirmed absent (checked by reading, not assumed)

The plan expected four things to drop. Reading the code shows three of them do not exist on this page, so there is nothing to keep or drop for them:

- **No interactive resampling or ECDF widget.** `{{chart:ecdf}}` and `{{chart:resample}}` are static matplotlib SVGs rendered at build time. `resample_frames` draws ten fixed imaginary campaigns with `seed=0`. The page has no sliders, inputs, buttons (other than glossary terms) or inline event handlers.
- **No in-page tutor.** No chat box, no network call at runtime. The one hit for "tutor" in the built HTML is the word "tutorial" in the vLLM section.
- **No per-module checkpoints.** No quiz, prediction prompt or stored answer. The page keeps no state (0 localStorage keys). Checkpoints exist in artifact 2's explainer (`tests/test_explainer_a2_checkpoints.py`), not in this one.
- **The jargon contract does exist, but it is short**: 13 terms in `terms.json`, enforced by a build gate plus a clickable glossary. See rows 37 and 38.
