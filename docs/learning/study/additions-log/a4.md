## Claims I could not verify

- "Fixed" (3.64 GiB) is budget minus logged KV; its split into weights, activations and buffers is not known. The pin's "give-up" (about 1.05 GiB an engine) is a subtraction; how that memory is used at run time is not measured.

- The calculator's "third model is not hot" holds for the swept skews up to 2.0 (checked with `hot_allocation`); beyond that it was not checked.
